◈ FlowLedger

Python · Streamlit · SQLite

Business workflows,
made simpler.

FlowLedger is a business workflow automation prototype for importing invoices, validating records, preventing duplicates, tracking approval statuses, and producing supplier reports.

Explore GitHub Repository ↗

Invoice Import

Import sample invoice data from CSV files.

Data Validation

Check records and identify duplicates before processing.

Approval Tracking

Follow invoices through approval and payment statuses.

Reporting

Review supplier summaries, audit activity, and workflow metrics.

How it works

CSV invoice data → validation → SQLite storage → status updates → reports and audit trail.

Run the interactive application

Clone the repository, install the Python requirements, and start the Streamlit app locally. This GitHub Pages website is a static project showcase, not the running Python application.
